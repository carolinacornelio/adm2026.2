ERP - PROTÓTIPO HTML/CSS

As telas são somente a estrutura visual do sistema.

Os campos de cadastro, compra e venda estão LIMPOS:
- sem valores preenchidos via HTML;
- sem dados reais;
- sem lógica de cadastro;
- sem lógica de pesquisa;
- sem lógica de compra/venda;
- sem conexão com banco.

Os placeholders servem apenas para orientar o usuário sobre o que deve ser digitado.

Arquivos:
- dashboard.html
- pessoas-cadastro.html
- pessoas-listagem.html
- produtos-cadastro.html
- produtos-listagem.html
- compras.html
- vendas.html
- estoque.html
- style.css
